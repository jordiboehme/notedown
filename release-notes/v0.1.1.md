# Don't panic.

A small fix for the OCR with a server on another machine, and the first release the app can install by itself.

## Fixes

- After a password change the OCR stopped with "the server refused the token". The app offered no way back, only a command for the terminal. Now the OCR page and Setup ask for the password and connect the OCR again. Logging in again on the Account page reconnects it too.

## Breaking changes

None.
