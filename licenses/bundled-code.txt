# Source: llama-cpp-sys-2 0.1.161 (crate license MIT OR Apache-2.0), which
# builds llama.cpp from its llama.cpp/ folder with the mtmd feature. The texts

# file), vendor/miniaudio/miniaudio.h (end of file), vendor/sheredom/

# Which vendored parts are linked, checked on 2026-11-17 with
#   cargo build --release -p notedown
# (aarch64-apple-darwin, default features) and nm on target/release/notedown.
# stb_image and miniaudio are compiled as static functions (MA_API static),
# so "nm -gU ... | grep -E 'stbi_|ma_|nlohmann|httplib'" does not see them
# and its "ma_" also matches "llama_". These counts were used instead:
#   nm target/release/notedown | grep -cE 'ZL[0-9]+stbi__'    98   stb_image: linked
#   nm target/release/notedown | grep -cE 'ZL[0-9]+ma_'       206  miniaudio: linked
#   nm target/release/notedown | grep -c  '_subprocess_create' 2   sheredom subprocess.h: linked
#   nm target/release/notedown | grep -cE ' T _sha256_hash$'   1   hash/sha256 (with rotate-bits): linked
#   nm target/release/notedown | grep -c  'llamafile_sgemm'    1   llamafile sgemm: linked
#   nm target/release/notedown | grep -ci 'nlohmann'           0   nlohmann json: not linked
#   nm target/release/notedown | grep -ci 'httplib'            0   cpp-httplib: not linked
#   nm target/release/notedown | grep -c  'XXH'                0   hash/xxhash: not linked
#   nm target/release/notedown | grep -c  'vendor_hash'        0   hash/sha1 (namespace vendor_hash): not linked
# Only the linked parts are listed below. Check again when llama-cpp-2 or
# llama-cpp-sys-2 changes version.
Code built into the notedown program
====================================

The OCR side of the notedown program (macOS) is built with llama.cpp. The
llama-cpp-sys-2 crate builds it from source and links it into the binary.
llama.cpp in turn bundles the parts listed after its own license. Each part
comes with the license text from its source file.
