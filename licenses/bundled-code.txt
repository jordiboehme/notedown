Code built into the notedown program
====================================

The OCR side of the notedown program (macOS) is built with llama.cpp. The
llama-cpp-sys-2 crate builds it from source and links it into the binary.
llama.cpp in turn bundles the part listed after its own license. Each part
comes with the license text from its source file. The last section names the
Apache-2.0 code inside pagevision, the page reading library of notedown.
