# The ink is dry.

The first release of Notedown: your Supernote syncs with your own Mac, its handwriting turns into Markdown and your AI agent can read it.

## New & Noteworthy

### The Mac app

- Notedown lives in the menu bar. One click shows when the Supernote last synced, how much OCR is left and what your agent read.
- Setup takes a new Mac from nothing to a working sync, without the terminal: the server, the account, the OCR model, the backup and import of the Supernote, the first sync and an agent.
- The import refuses an old backup. A file that is missing on the server would get deleted on the Supernote, so the backup must be fresh.
- The library shows every folder of the Supernote as a tree or in columns. Drop files from Finder into any folder, move them, rename them and get them back from the recycle bin.
- Open a note to see its handwritten pages next to its Markdown. Both sides scroll together.
- Notifications tell you when the Supernote synced, when OCR is done, when an agent read new notes and when something needs a look. They are off until you turn them on.
- The app updates itself. It asks first.

### Sync and OCR

- `notedown serve` is a private cloud for the Supernote: Ratta's sync protocol on your own machine, with digests and to-dos.
- The OCR runs on the Mac with a local model. Nothing leaves your network. Diagrams come out as Mermaid.
- The model frees its memory after 5 minutes without new pages. Settings: OCR, if you want it longer or shorter.
- `notedown mcp` gives an agent the notes over MCP. It reads only what changed since its last visit.
- Server and OCR can run on two machines: the server on a Raspberry Pi, the OCR on the Mac.

### Install it your way

- macOS: the app as a signed dmg, or `brew install --cask jordiboehme/tap/notedown-app`. The command line tool: `brew install jordiboehme/tap/notedown`. Apple Silicon only.
- Linux: a `.deb` for arm64 and amd64 with a systemd service, plain archives and an image at `ghcr.io/jordiboehme/notedown`. No OCR there.
- Every file is in `SHA256SUMS`, signed with cosign, with an SBOM and a build attestation. docs/install.md shows how to check them.
