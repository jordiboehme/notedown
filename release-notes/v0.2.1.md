# Follow the breadcrumbs.

A small release for the library: it shows where a note lives, and the lists sort the way you want.

## New & Noteworthy

- Open a note and the library shows where it is. The tree opens down to its folder and selects it. Back still goes where you came from.
- The toolbar line now shows the path of what you see, with the folders and the note name. Click a folder to show its notes and files. A long path is cut on the left, and the tooltip shows all of it.
- Every list can be sorted by each of its columns: New, All notes, a folder and the recycle bin. Click a column head for ascending, again for descending. Names sort like in the Finder. Notedown remembers the order of each list.
- The OCR page in Settings names the models with their licences, and each name links to the page of the model.

## Fixes

- A right click on a page showed the image menu of the web view, and most of it did nothing. Now it is our own menu: Copy Image, Save Image... and Share.... The web view menu is also gone from the rest of the window, except in text fields and on selected text.

## Breaking changes

None.
